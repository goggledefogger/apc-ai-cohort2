Student Resource
Google AI Studio is a free, web-based workspace for prototyping with Google’s Gemini models. No installation, no credit card — sign in with a Google account and start prompting. It gives you direct access to frontier AI models with features like multimodal input, code execution, and app building. Think of it as Google’s version of a playground where you can test, build, and export to production.
What AI Studio Is (and Isn’t)
It Is
  • A free prototyping environment for Gemini models
  • An API playground where you can test prompts and export working code
  • A “vibe coding” tool that builds full apps from descriptions
  • A multimodal workspace: text, images, audio, video, PDFs
  • A way to generate images, video, music, and speech — all in one place
It Isn’t
  • A code editor like Cursor or VS Code — it doesn’t manage your project files
  • The same as Gemini chat (gemini.google.com) — AI Studio is the developer-facing tool
  • The same as Vertex AI — that’s Google Cloud’s enterprise version
  • A replacement for a full development environment
  • Private on the free tier — your prompts may be used to improve Google’s models
URL: aistudio.google.com — sign in with any Google account to get started.
Getting Started
Sign in with Google → Pick a mode → Write a prompt → Iterate → Get Code / Deploy
Mode Chat
Conversational prompting. Ask questions, iterate on responses, test system instructions. Where most people start. Good for exploring what a model can do before building anything.
Mode Build (“Vibe Coding”)
Describe an app in plain language and Gemini generates a working application. Preview it live, then deploy to Google Cloud Run with one click. No coding required to get a prototype running.
Mode Stream Realtime
Share your screen, camera, or both and have a live voice conversation with the model about what it sees. Useful for walking through a UI, getting feedback on a design, or explaining a concept hands-free.
Feature Compare Mode
Test the same prompt across multiple Gemini models side by side. Helpful for understanding which model handles your use case best before committing to one.
Available Models
AI Studio gives you access to multiple Gemini models. Each has different strengths, speeds, and pricing. The model picker in the top-left lets you switch between them.
Model Best For Speed / Cost Free Tier?
Gemini 2.5 Pro Complex reasoning, coding, analysis. 1M token context window (largest available) Slower, most capable Yes (rate-limited)
Gemini 2.5 Flash Best balance of speed and quality. Good default for most tasks Fast, very capable Yes
Gemini 2.5 Flash Lite Quick answers, high-volume tasks, low-cost automation Fastest, cheapest Yes
Gemini 3 Flash Next-gen performance. Benchmarks near 2.5 Pro but much faster Fast, frontier-class Yes (preview)
Gemini 3.1 Pro Most advanced model. Agentic coding and complex tasks Slowest, most powerful No (paid only)
1 million tokens is roughly 1,500 pages of text or 30,000 lines of code. That’s significantly more context than most other AI tools. You can paste entire codebases, long documents, or hours of transcripts and ask questions about them.
Key Features
Feature System Instructions
Set the model’s persona, tone, and rules before the conversation starts. These persist across the entire chat. Example: “You are a friendly tutor. Explain concepts using everyday analogies. Keep responses under 200 words.”
Feature Multimodal Input
Upload images, audio, video, PDFs, and documents alongside your text prompts. Ask about what’s in a photo, transcribe audio, analyze a video, or extract data from a PDF. Gemini handles them natively — no plugins needed.
Feature Grounding with Google Search
Toggle this on and the model pulls live information from the web before responding. Useful when you need current data, recent news, or facts the model might not know from training alone. Free tier includes 5,000 grounded prompts per month.
Feature Structured Output
Define a JSON schema and the model responds in that exact format. Useful for automation, data extraction, or any task where you need predictable, parseable output rather than free-form text.
Feature Code Execution
The model can write and run Python code in a sandboxed environment. It uses this to solve math problems, process data, create charts, and verify its own work. You see both the code and the output.
Feature Get Code
Once your prompt works, click “Get Code” to export it as working API code in Python, JavaScript, or other languages. Takes you from prototype to production without rewriting anything.
One limitation: You can’t enable Grounding with Google Search and Structured Output at the same time. Disable one before enabling the other.
Media Generation
AI Studio isn’t just for text. It includes built-in tools for generating images, video, speech, and music — all from the same interface.
Type Model Details
Images Imagen 4, Gemini image models Text-to-image generation and image editing. Gemini’s native image generation can also create images with readable text in them
Video Veo 3.1 Generate video clips from text descriptions. Useful for prototyping visual concepts
Speech Gemini TTS models Text-to-speech with natural-sounding voices. Available in Pro and Flash variants
Music Lyria Generate music clips and soundscapes from text descriptions
Most media generation is paid. Image, video, and music generation typically require billing enabled. Text-to-speech has some free-tier access. The text-based Gemini models remain the core free offering.

Pricing & Free Tier
Free What You Get for $0
  • Access to Gemini 2.5 Pro, 2.5 Flash, 2.5 Flash Lite, and 3 Flash
  • No credit card, no waiting — sign in and start
  • Rate-limited: roughly 5–15 requests per minute depending on model
  • 5,000 Google Search grounded prompts per month
  • Full multimodal input (images, audio, video, PDFs)
  • Code execution, system instructions, structured output
Tradeoff: Free-tier data may be used by Google to improve their models. Enable paid billing for data privacy.
Paid When You Need More
  • Pay-per-use API pricing (no monthly subscription required)
  • Gemini 2.5 Flash: ~$0.30 per million input tokens — very affordable
  • Gemini 2.5 Pro: ~$1.25–$2.50 per million input tokens
  • Higher rate limits and guaranteed availability
  • Data privacy — your prompts are not used for training
  • Access to paid-only models like Gemini 3.1 Pro
  • AI Pro subscription ($19.99/mo) for higher limits and Gemini 3 Pro access
AI Studio vs ChatGPT vs Claude
These are different tools with different strengths. This isn’t about which is “best” — it’s about which fits what you’re doing.
Dimension AI Studio ChatGPT Claude
Free tier Most generous. API-level access to frontier models at no cost Limited. GPT-4o mini with usage caps Limited. Claude Sonnet with usage caps
Context size 1M tokens (largest) 128K tokens 200K tokens
Multimodal Text, images, audio, video, PDFs — most comprehensive Text, images, audio, code Text, images, code
Media generation Images, video, music, speech — all built in Images (DALL-E). No video or music No built-in generation
App building Vibe coding + one-click Cloud Run deploy Canvas for code Artifacts for code
Code export One-click export to Python/JS API code API playground is separate API playground is separate
Standout strength Multimodal breadth, free tier, Google ecosystem Polished chat experience, creative tasks Deep analysis, instruction-following, writing quality
Tradeoffs, not rankings.
AI Studio — best free tier and multimodal breadth. But the interface is more developer-oriented, the chat experience is less polished, and free-tier data privacy is a real consideration.
ChatGPT — most mature consumer experience with plugins and browsing. But the free tier is limited and the API playground is separate from the chat product.
Claude — strongest for careful analysis, following complex instructions, and writing. But no built-in media generation and a smaller context window than Gemini.
Tips That Matter
  1. Start in Chat mode. Spend time understanding how Gemini responds before jumping into Build mode. Get a feel for the model first. Chat mode is low-stakes and teaches you prompting patterns that transfer everywhere.
  2. Write system instructions early. They shape how the model responds to everything. Set tone, persona, and constraints before you start prompting. Example: “Respond in plain language. If you’re unsure about something, say so.”
  3. Use Google Search grounding for current information. The model’s training data has a cutoff. Toggle on grounding when you need today’s facts, prices, or news. 5,000 free grounded prompts per month is plenty for learning and prototyping.
  4. Adjust thinking level. Set to High for complex reasoning or coding, Low for quick answers. This controls how much the model reasons before responding. Higher thinking = better results on hard problems, but slower and more tokens used.
  5. Use “Get Code” to export. Once a prompt works well in AI Studio, export it as Python or JavaScript code you can use in your own projects. This bridges the gap between prototyping and production.
  6. Start new chats for new tasks. Long conversations degrade quality as the context fills up. Fresh contexts give better results. Same principle as Claude Code — context rot is real across all AI tools.
  7. Try Compare mode. Test the same prompt across models to see which handles your use case best. Quick way to learn model strengths. Especially useful when deciding between Flash (fast) and Pro (capable) for a specific task.
  8. Be aware of the free tier data tradeoff. Google may use your free-tier interactions to improve their models. Don’t put sensitive or private data into the free tier. Enable paid billing if you need data privacy guarantees.
